Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce

📌 Overview

A Salesforce-based customer support automation system that analyzes support ticket descriptions, predicts ticket priority, and automates task assignment using Agentforce and Salesforce Flow.

🎯 Objectives

Automatically classify tickets as High, Medium, or Low priority.
Assign high-priority tickets to appropriate support agents.
Create urgent tasks automatically for critical tickets.
Reduce manual effort and response time.
⚙️ Priority Logic

Priority| Keywords 🔴 High| urgent, not working, failure 🟡 Medium| issue, slow, delay 🟢 Low| None of the above

🛠️ Technologies

Salesforce
Agentforce
Salesforce Flow
Custom Objects & Fields
🔄 Workflow

Customer Ticket → Agentforce → Analyze Description → Determine Priority → Assign Agent → Create Task for High Priority → Final Response
